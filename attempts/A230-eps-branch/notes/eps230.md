# A230 — Rule EPS: all candidates, the polygon taper, and Rule NS at the WEDGE

PI, 2026-09-15 09:00: *"F1 (BL10) should trigger EPS before F2 does (BR01), so there may need to be something to
make sure it checks all candidates."*  Proof object `docs/proofs/lemma_eps.md` (A227); this attempt discharges its

## 0. What A227's 1.1 candidates per node actually was

A227's replay evaluated **every** candidate `candidates()` returned — the loop in `eps227.evaluate` never stopped
at the first — so the 322 evaluations over 294 nodes were **not** a scan that halted early.  They were A224's
**filter**: `snap224.near` asks that the role's box **centre** lie within `δ = 0.06` (ℓ∞) of the slot centre and
that **every** piece's tilt bin be within `3°` of alignment.  A role whose box is wide (its centre far from the
slot, its poses still reaching into the cell) or whose pieces straddle alignment was never offered.  So the PI's
"F1 should trigger before F2" was blocked at the filter, not at the loop.

**A230's candidate test** (`eps230.candidates`, flag `A230_ALLCAND`, default on with the rule):

* ℓ∞ distance from the slot centre to the role's position **BOX** (0 when the centre is inside it) ≤ `δ`;
* **some** piece's tilt bin within `DEG` of alignment (A224 asked for every piece);
* both cells a role can be near-simple in are therefore returned, and every pair is evaluated;
* deterministic order: **smallest box volume first**, then role, then slot — the tightest geometry is tried first
  and the verdict is taken from the first candidate whose cell is left with `< 2` distinct non-pin meeters.

Soundness is untouched: Lemma EPS-4 bounds `⋃_box (C \ F)` for an **arbitrary** pose box, so the near-simple
filter is a *heuristic* that only decides where the rule is worth running (for a far or wide box `𝒲(box) = C`,
the targets are trivial and nothing is struck).  Measured on Y0865 g1's 163 recorded nodes: **271 candidates
(1.66 per node) against A227's 1.1, 170 of them returned only by the wider test.**

## 1. [T] The kill condition, restated as Theorem FC's count

A candidate `(F, C = B_p⁺)` kills when the cell is left with **fewer than two distinct non-pin meeters**: Theorem FC
gives two, `F` is at most one of them, and the other must have an interior point in a target of `(F, C)`
(EPS-3/4 on the free sides, EPS-5/GATE on the backed ones).  So *no named survivor* + *the anonymous clause
certified empty* is the contradiction.  This is exactly A227's `dead` test, now stated as the count the PI asked
for and evaluated at every candidate rather than the first.

## 2. [T] TAPER — the strike against the exact wedge polygon (s.7 [C]1)

`eps230.misses_poly_t(x0,x1,y0,y1,t0,t1, poly)` is A161's separating-axis test with the rectangle replaced by the
convex wedge polygon:

* the Minkowski difference `D = {box corner} − {polygon vertex}` (its extreme points; the functional is linear, so
  the minimum over `D` is attained there);
* **family A′** — the polygon's own edge normals `w` (both signs) plus the four axis directions.  The square's
  support radius in an unnormalised direction `w = (a, b)` is `(|a cos + b sin| + |b cos − a sin|)/2`, bounded over
  the tilt bin by interval arithmetic in `(cos, sin)` (`cos` decreasing, `sin` increasing in `t`) — the same
  relaxation EPS-4 already uses.  Separated when `min_D ⟨d, w⟩ ≥ r(w)`; both sides scale with `|w|`, so no
  normalisation is needed;
* **family B** — the square's own two normals at radius `½`, via `chordlane._proj_min_exact` over `D`.

Sound a fortiori: the true wedge ⊆ the polygon ⊆ its bounding rectangle, so a strike here is a strike.  The
rectangle test is still tried first (cheap); the polygon only runs when the rectangle fails, and a wedge whose two
polygons share a bounding box makes no taper claim.  Randomised check: 3 229 claimed separations over random
polygons and pose boxes, 0 contradicted by 40 sampled poses each.

## 3. [T] NS AT THE WEDGE (s.7 [C]3)

At a candidate where **exactly one** named role `M` survives and the anonymous clause is **certified empty**
(`anon_cells == []`, not "no claim"), `M` *is* Theorem FC's second meeter, so it has an interior point in one of
the targets it can still reach.  Let `W` be the union of those targets (taken from `F`'s **hull** box, a superset
of every piece's targets, so the disjunction is sound).  The split is

| child | hypothesis | outcome |
|---|---|---|
| `epsns-misses` | `M` misses every target of `W` | **DEAD at once by FC+EPS** — the cell keeps `F` and nothing else; the certificate is the target list, the struck roles' miss certificates and this branch's own hypothesis (no cascade is run) |
| `epsns-meets` | `M` has an interior point in `W` | `M`'s pieces clipped to the poses that reach `W`, then the ordinary coarse round and the leaf rules |

**The clip** (`epsns230.apply_wedge`) is exact and piecewise: a piece is dropped when A161's test separates it from
**every** target of `W`; what survives is intersected with `W`'s bounding box dilated by `h = (cos + sin)/2` over
that piece's own bin (EPS-6's box bound — the family-A axis of the same test).  An empty result is itself a kill
(`EPS-WEDGE-EMPTY`).  `pg.roles[M]` is re-taken as the hull of the surviving pieces, exactly as Lemma ROLE-SPLIT
does.

*Depth-cap accounting* is Rule NS's: the split counts one level (only `rsplit` is charged to a per-role cap), and
`eps_try` refuses to split at the depth or node cap or past the wall.  *Fresh-table proviso*: the caller runs
`N6.cascade` on the `epsns-meets` child before any further branching, so the option table the next rule reads is
fresh (Lemma CT) — the anonymous clause of the next EPS evaluation is therefore legitimate.

*Why it can kill where whole-cell NS could not.*  Rule NS splits on "`M` meets the **slot**"; its MISSES child is
an ordinary hypothesis the cascade must still refute.  The wedge split's MISSES child is refuted by the rule that
produced it, with no search at all, and its MEETS child arrives with `M` already clipped to a set of depth
`≲ δ + θ₀/2 ≈ 0.09` around one side of the cell — the PI's F1/F4/H configuration on Y0865, where `H`'s edge
crosses `x = 2` at `y = 0.9916` inside the right wedge target.

## 4. Flags and the wiring

| flag | default | effect |
|---|---|---|
| `A230_EPS` (or `A227_EPS`) | **off** | the whole rule.  Off ⇒ pass-6 behaviour byte for byte (`L11.EPS_ON` is read once at import and guards every new path) |
| `A230_ALLCAND` | on | the wider candidate test of s.0 |
| `A230_TAPER` | on | the polygon strike of s.2 |
| `A230_WEDGE_NS` | on | the split of s.3 |
| `A230_EPS_C` / `A230_DEG` | A224's `0.06` / `3.0` | the candidate filter |
| `A230_MAXTESTS` | 40000 | exact tests per node before "no claim" |

`leaves211.eps_eval` / `eps_branches` / `eps_apply` are the entry points; `tree211.eps_try` runs the rule as leaf
rule (0′) and after the coarse round at internal nodes, beside Rule SNAP, and returns `"EPSNS"` to hand the tree
the split.  `step_key` carries `("epsns", slot, role, kind, W)` so Lemma INHERIT keys the branch correctly.
