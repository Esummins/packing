# A07-lp-dual — LP / measure ("fractional unavoidable set") lower bound for s(11)

Owner: LP agent (postdoc, optimisation / LP duality / rigorous numerics). Started 2026-08-16.
Status: RUNNING (see bottom for the live table). This file is updated incrementally.

## 1. Formulation

Container S = [0,s]^2. A non-negative measure mu on S is *blocking* if mu(Q) >= 1 for every closed
unit square Q contained in S (any orientation). If a blocking mu has mu(S) < n then n pairwise-disjoint
closed unit squares cannot lie in S (each carries mass >= 1), and by scaling s(n) >= s
(if n squares with disjoint interiors fit in side s' < s, scale by s/s' > 1: their concentric closed
unit squares are pairwise disjoint in [0,s]^2). Define

    tau*(s) = inf { mu(S) : mu blocking }          (semi-infinite LP)
    nu*(s)  = sup { total weight of a fractional packing } = LP dual
              (non-negative measure on placements (c,theta) with pointwise coverage <= 1)

Weak duality tau* >= nu* is trivial; numerically the two coincide (HiGHS primal/dual objective).
Point sets (Stromquist / Friedman "unavoidable sets") are the special case mu = sum of n-1 Dirac masses;
so tau*(s) < n is at least as strong as any pure unavoidable-set argument, and the largest s with
tau*(s) < n is the CEILING of every measure-type argument. tau* is monotone non-decreasing in s
(restriction of a blocking measure for s' > s to [0,s]^2 is blocking for s).

WLOG mu is D4-symmetric (average over the symmetry group of S; constraints and objective are invariant),
so theta may be restricted to [0, pi/4] and centres to a C4 fundamental quadrant.

## 2. Discretisation — two versions

**v1 (`lp_measure.py`), atoms on a grid.** Atoms at (i s/N, j s/N), variables = D4 orbits, rows =
placements generated by a heuristic separation oracle (histogram lower bounds on a fine (c,theta) grid,
exact evaluation, pattern-search refinement, theta in [0,pi/4] with 181 values, c-step 0.01), HiGHS
dual simplex with warm start.  Result at s = 3.80: h = 0.1 -> tau = 11.069, h = 0.05 -> tau = 11.000
(exactly).  Diagnosis (`analyze_packing.py`, `plots/test_s3.80_N76.png`): the dual "fractional packing"
of weight 11 has true maximum coverage 1.5 — it is a near-packing of 11 squares whose pairwise overlaps
are thin slivers that avoid all grid points.  Coverage is only enforced at grid nodes, so grid atoms
over-estimate tau* by O(h) in a way that does not go away quickly with refinement.  Grid atoms are the
wrong discretisation for this problem.

**v2 (`lp_measure2.py`), free atoms = simultaneous row and column generation.**
- Variables: D4-orbits of atoms at arbitrary positions (weight per point, objective = #points).
- Rows: placements (cx,cy,theta), coefficient = number of orbit points inside the eps-shrunk closed
  square |R(-theta)(p-c)|_inf <= 1/2 - EPS_GEO, EPS_GEO = 1e-4 (robustness margin so that the interval
  verifier never has to prove that an atom lies exactly on a boundary).  Centres restricted to the
  admissible region cx,cy in [w/2, s-w/2], w = cos+sin (square inside container).
- Row oracle: as v1 (theta grid 91 or 181 values, c-step 0.02/0.01, then pattern search in (c,theta)).
- Column oracle: expand the dual y (weight y_i/8 on each D4 image of placement i) and find points of
  maximum coverage (grid 0.005 on the fundamental triangle + arrangement vertices of the placement
  squares perturbed into neighbouring cells + pattern search); add the D4 orbit of each over-covered
  point (coverage > 1) as a new column.  This is exactly the missing dual separation: it puts atoms
  where the fractional packing over-covers, killing the sliver artefact.
- Iterate: solve, add <=1200 rows, add <=60 orbits; when maxcov < 1.003 stop adding columns and run
  row generation to convergence (primal-feasible mu; that value is a valid upper bound on tau*(s) for
  the given atom set), finishing with a fine row search (361 theta values, c-step 0.005).
- Checkpoint (`results/*_state.json`) every iteration; `--state` resumes with all rows/orbits.

## 3. Rigorous verification pipeline (`bb_verify.py`, `exact_check.py`, `make_cert.py`)

Certificate JSON format (FROZEN 2026-08-16 — A08 writes an independent verifier against it):

```
{
 "format": "measure-certificate-v1",
 "n": 11,                          # claim s(n) >= s
 "s": "19/5",                      # exact rational string
 "atoms": [["x","y"], ...],        # ALL atoms as exact rational strings (D4 images expanded; the
                                   #  verifier must NOT assume any symmetry)
 "weights": ["p/q", ...],          # same length, positive rationals
 "total": "p/q",                   # exact sum of weights, must be < n
 "claim": "...", "provenance": {...}
}
```
Statement to verify: for every closed unit square Q contained in [0,s]^2 (any orientation),
sum of weights of atoms in Q  >= 1.   (Then total < n  =>  s(n) >= s.)

Verifier: branch and bound over (t, cx, cy), t = tan(theta/2) in [0,1] (theta in [0,pi/2] — full range,
no symmetry used), cos = (1-t^2)/(1+t^2) decreasing, sin = 2t/(1+t^2) increasing on [0,1] => exact
rational enclosures.  Dyadic boxes: t in [i,i+1]/2^lt, cx in s[j,j+1]/2^lx, cy in s[k,k+1]/2^ly.
A box passes if (a) it contains no admissible placement (x2 < w_lo/2 or x1 > s - w_lo/2, same for y),
or (b) the atoms provably inside Q for all parameters of the box (interval arithmetic on
ux = (px-cx)cos + (py-cy)sin, uy = -(px-cx)sin + (py-cy)cos, |ux|,|uy| <= 1/2) have weight >= 1.
Otherwise bisect the widest dimension (theta-width ~ 2 dt).  Boxes narrower than min_width = 1e-5 in
every dimension are failures (witness -> new LP row: rigorous separation loop).
Float pass: numpy, vectorised over boxes, every interval widened by 1e-12 after each operation
(rigorous modulo IEEE-754); region-parallel (t split in 8, c in 16x16, per-region atom candidate
pruning by dist(p, c-box) <= sqrt(2)/2).  Exact pass (`exact_check.py`): re-checks every leaf
(dyadic box + atom subset) with Python Fractions only.

## 5. n = 10 calibration
tau*(3.65) = 9.364 < 10; tau*(3 + 1/sqrt2 = 3.7071) = 10.000 exactly (stable from iteration 10 on):
the LP is tight at s(10) — the 10-packing exists, so nu* >= 10, and the LP finds a blocking measure of
mass exactly 10, i.e. the measure argument reproduces s(10) >= 3.7071 (Stromquist's exact value)
with no slack in either direction.
