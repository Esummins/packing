# A171 usage — the eight lines every multi-box construction must run (line 6 by A172, lines 7–8 by A173)

1. **Build the node from the boxes, nothing else**: `nd = multibox.Node({"H": (x0,x1,y0,y1,th0,th1), ...}, s=S_RAT)` — one named box per square, `t=True` in `mk_box` if the tilt interval is given in `t = tan(θ/2)`.
2. **Normalise before anything looks at the geometry**: `nd.normalise(s, nsub=4, max_iter=10, refine=2)` — container clip (all poses inside `[0,s]^2`, per tilt sub-bin, the sacrificed wall slivers recorded with their area) then mutual clip of every box against every other box's `K'` to a fixed point, `K'` and the exact axis core rebuilt after each pass. An `EmptyBox(name)` is **not an error to retry**: the case is dead by the pair leaf (`shared_point_same_square`) — record it and move on.
3. **Assert, and keep the report**: `rep = nd.assert_invariant()` — exact rational `K-CONTAINER`, `K-DISJOINT`, `POSE-CONTAINER`, `POSE-CONTAINER-STRICT`, `CLIP-FIXPOINT`; it raises `InvariantError` listing every violation. `rep["diagnostics"]` carries the residual `escape_frac` / `core_meet_frac` and `rep["sliver_area"]` the strict-container cost — if `core_meet_frac` is still large the node is loose, so raise `nsub`/`refine` before you trust a count.
4. **Only then consume it**: `nd.chord_rows(lines)` (A144 rows), `nd.lane(cell, line)` (A141 cover + A161 exact miss test), `nd.misses_cell(cell)`, `nd.figure(path, extras=[...])`. All of them run off the clipped boxes; `chord_rows` and `lane` **refuse to run** on an un-normalised node (`RuntimeError`), which is the guard A165/A168 lacked. Hand an LP `nd[name].core` / `nd[name].pc`, never `nd[name].box0`.
5. **Ship the figure with the verdict on it**: `nd.figure(...)` prints the invariant's per-check result, the kept fractions and the residuals on the page, draws every `K'` solid and the **extreme poses** as thin outlines (real poses, not an envelope) — so a panel that lies about clipping cannot be produced without the lie being visible next to it.
6. **Build every derived object from the PIECES, never from their hull (A172).** `K'(B)` is the **exact rational intersection of the per-piece `K'`** — one `polycore.build` per (tilt sub-bin, centre rect) piece, intersected in `Fraction`s, simplified only by DELETING vertices (inward, never outward), and then **every vertex re-certified with `polycore.vertex_ok` against EVERY piece**. That certification is the proof (a point in every pose of every piece is in every surviving pose, and `Q(c,θ)` is convex), so the construction is allowed to be a fast heuristic; the exact axis core is built the same way (largest square about the intersection's centroid, corners certified per piece, A135's pattern). `normalise(..., kmode="union")` and `MBox.union_pc()` keep A171's union-hull `K'` as the automatic fallback and as the diagnostic. Why it matters: the hull of the survivors forgets a clip that removed different slabs in different tilt sub-bins, so `K'` barely grows and the cascade barely bites — on A168's S2 node the per-piece `K'` is 0.709336 / 0.799343 / 0.774356 against the hull's 0.658006 / 0.798164 / 0.740065 on the same pieces, and driving the fixed point with it takes the kept fractions H 0.4408 → 0.3584 and D 0.0882 → 0.0722. It costs time (that node: 2.1 s → 13.1 s), so `kmode="union"` is the lever if a sweep is wall-time-bound — but a node you are about to draw, price, cover or hand to an LP should be normalised with the default.

7. **Turn on the LONELY CLIP wherever a box is a corner meeter (A173).** `nd.normalise(..., corners={"D": ("TR", multibox.C_WIDEN)})` — or just `corners={"D": "TR"}`, which uses `C_WIDEN = 1 + w` (the K0-WIDEN box, A168's `cas168.W0_RAT`, reproduced exactly). A169's **Theorem B** (`docs/proofs/sideband.md` §3, row **R3** §6) says a pose that admits **no second meeter** of that corner box — a *lonely* pose — cannot occur in a K0-BLOCKED packing, so it is a NO-family at every node and the box may be **clipped** by it. `lonely_clip` does it per piece: it drops a whole tilt sub-bin when the criterion certifies the piece lonely, and otherwise bisects the four axis slabs (`PIN._bisect_boundary`, the same machinery as the container and mutual clips), recording every removal with its area in `mb.trace` and the total in `mb.lonely_removed` / `rep["lonely_removed"]`. It runs **at every pass, before the mutual clip**, which is the whole point: the survivors rebuild a larger `K'`, and the cascade carries that growth into the other boxes. `lonely_refine=1` bisects the tilt sub-bin of a piece that is only *partly* lonely first (tautologous), which is what catches "lonely above 15°, not below". Losing every piece raises `EmptyBox` — A168's whole-role R3 kill recovered as the limiting case. **Do not use `resume168.lonely_role` instead**: it kills a role only when *every* pose is lonely, so a role that is 90 % lonely keeps all of its poses, `K'` never grows and the cascade is lost — measured on A168's ALIVE nodes in `attempts/A173-lonely-clip/results/table173.md`. **Soundness grade**: the criterion is a *sufficient* condition for lonely, so only certified slabs go; clause (P) is exact (A131's rational clip against the pressed square), the three support clauses inherit A168's **[S]** grid-plus-Lipschitz grade — the same grade as the R3 kills already in the corpus, no better. The port is cross-checked against `resume168.lonely_box` on 500 random boxes (identical verdicts) by `tests/test_multibox.py` case (f).

8. **Never key a cache on `id()` (A173, a bug that was live for two attempts).** `Bin.radii` memoised its exact per-edge radius bounds under `id(obs)`. `normalise` compiles a FRESH obstacle per box per pass and drops the previous pass's, CPython hands the freed address straight back, and a `Bin` that outlived the old obstacle then answered the NEW one with the OLD one's bounds — wrong bounds inside the exact dead test, in either direction, i.e. an **unsound clip**, hitting nondeterministically (two aliases in test case (a) alone, which is why `a2.invariant_after` flickered PASS/FAIL between runs). `Obstacle` now carries a monotone `uid` and the cache is keyed on that; case (a3) rebuilds an obstacle at a recycled address and requires the fresh radii. The speed the accidental hits were stealing is now taken **legitimately** by `MBox.obstacle()`, which caches the compiled obstacle under the exact rational CONTENT of `K'` (or the core's five exact parameters) and so returns the same object — same `uid` — for as long as `K'` really is unchanged. Rule: a cache key must be the thing's IDENTITY-FOR-EVER or its CONTENT, never its address.
