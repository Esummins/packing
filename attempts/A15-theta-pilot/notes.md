# A15-theta-pilot — Lovász–Schrijver ϑ′ vs the point-clique LP on a discretised placement graph (I-L9 pilot)

Owner: SDP agent (postdoc, SDP / discrete geometry). 2026-08-19. Status: **done-success (pilot, ~4 h)** (resumed from disk once: the first process died after writing graph.py).

Question (I-L9). On the SAME finite placement graph G (nodes = placements (cx,cy,θ), edges = interior overlap),
compare the point-clique LP value ν*_G (the lab's Theorem-1 LP restricted to the node set) with ϑ′(G)
(Lovász–Schrijver / Schrijver theta: max Σ_ij B_ij, B ⪰ 0, B ≥ 0, tr B = 1, B_ij = 0 on edges) at s = 3.84, 3.85,
3.87 (+ 3.80 sanity, + the mid-tilt restricted graph θ ∈ {0°} ∪ [30°,36°] where the continuum LP is exactly 11.000).
α(G) ≤ ϑ′(G) ≤ ϑ(G) ≤ χ̄_f(G) ≤ ν*_G (point-cliques are cliques of G), so ϑ′ is never weaker than the LP on the
same graph and sees odd cycles (ϑ(C₅) = √5 < 5/2) — i.e. potentially the ¼-weight fractional structures of A10–A14.

**This is a comparison of relaxations on a finite subgraph, NOT a bound on s(11)**: the grid graph is an induced
subgraph of the continuum conflict graph, so α(G) ≤ α(G_cont); a value < 11 on G proves nothing about s(11). The
question is only whether ϑ′ is meaningfully below the LP on the same object (if yes, the continuous kernel version
of I-L9 is worth building).

## 1. Machinery (files)

- `graph.py` — node set = D4-invariant grid (centres cx = s/2 + k·h, θ ∈ {0, Δ, 2Δ, …} ∪ negatives mod 90°) restricted
  to the admissible centre region w/2 ≤ cx,cy ≤ s − w/2 (w = cosθ + sinθ), plus the D4 orbits of extra placements
  (the A12 ¼-structure support at 3.85/3.86/3.87 from `attempts/A12-region-rank-pilot/results/analysis_s*.json`, and
  the heaviest A07 dual placements at 3.84); D4 action as an (8,N) permutation array; node orbits; exact vectorised
  SAT interior-overlap matrix (agrees with A12's `geom.overlap_matrix`). Touching squares are NOT adjacent
  (independent sets = genuine packings; matches A07's ε-shrunk point coverage).
- `lp_point.py` — ν*_G: max Σ x_Q s.t. Σ_{Q ∋ p} x_Q ≤ 1 (p in the interior of Q), x ≥ 0, points generated by a
  row-generation loop (initial grid 0.05, then all over-covered points of a 0.005 grid + corners of the support
  squares' arrangement are added until max coverage ≤ 1 + 1e-6). HiGHS. The reported value is ν(points used);
  ν/maxcov ≤ ν*_G ≤ ν.
- `theta_sdp.py` — ϑ′(G) with the D4 symmetry block-diagonalised: an optimal B may be taken D4-invariant
  (average over the group), so B = Σ_ρ Σ_{r≤d_ρ} T_ρ^{(r)} X_ρ T_ρ^{(r)T} with X_ρ ⪰ 0 of size m_ρ (multiplicity of
  the irrep ρ ∈ {A1,A2,B1,B2,E}), T built orbit-by-orbit from the isotypic projectors P^{rr} = (d_ρ/8) Σ_g ρ(g)_rr π(g)
  (T is block-sparse: ≤ 8 nonzeros per row). Constraints: one per PAIR-ORBIT (edge orbits: B_ij = 0; non-edge
  orbits: B_ij ≥ 0), tr B = Σ d_ρ tr X_ρ = 1, objective = u^T X_{A1} u (u = T_{A1}^T 1). Fed directly to SCS
  (scipy.sparse, ~12 nonzeros per constraint row). Validated against the plain full-matrix cvxpy formulation on
  small graphs (N ≤ 150).
- `alpha.py` — α(G) by CP-SAT (reference only).
- `run_pilot.py` — driver; `results/*.json` (+ `_graph.npz`, `_B.npy`, `_B_diag.npy`, `_lp_x.npy`, `_scs_y.npy`), `logs/`.
- `continue_sdp.py` (warm-started SCS continuation), `support_sdp.py` (exact ϑ′ / LP / α on the D4-closed support
  subgraph of the approximate primal ⇒ tight lower bound on ϑ′(G)), `post_dual.py` (dual certificate spectrum),
  `analyze.py` (structure of x and B), `table.py`, `fixup.py` (merges continuation/support logs into the json files —
  the parallel writers raced).

## 3. Numerics of the SDP (what the numbers mean)

SCS is a first-order (ADMM) solver: its reported objective is NOT a bound.  Every run therefore reports a bracket
  θ_lb ≤ ϑ′(G) ≤ θ_ub  with
- θ_lb from the primal iterate: B cleaned (negatives clipped, edge entries zeroed, symmetrised), then B + δI with
  δ = max(0, −λ_min(B)) is feasible ⇒ ϑ′ ≥ (1ᵀB1 + Nδ)/(1 + Nδ);
- θ_ub from the dual multipliers: Z = λI − J − Y (Y from the pair-orbit multipliers, Y_ij = +y_E/(2|O|) on edge orbits,
  −y_P/(2|O|) on non-edge orbits; checked on small instances: min eig ≈ 0, non-edge entries = −1, diagonal = λ−1),
  then Z + δI (δ = −λ_min if negative) is a certificate with λ′ = λ + δ and non-edge slack ε = max(Z_ij + 1)_+ ⇒
  ϑ′(G) ≤ 1 + (λ′−1)/(1−ε)  (weak duality: ⟨Z,B⟩ ≥ 0 for any feasible B; the same inequality bounds α(G)).
  Floating-point eigenvalues only (not a rigorous certificate; it is a sanity bracket for a comparison pilot).
- Scaling: with tr B = 1 the entries of B are O(1/N) and SCS crawls (N = 606 test: 9.15 after 5000 iterations vs true
  ≈ 9.00); with tr B = N (objective divided by N) the same 5000 iterations give the bracket [9.004, 9.02]. All runs use
  tr B = N.  Symmetry reduction (blocks ≈ N/8, N/8, N/8, N/8, N/4 instead of one N×N cone) gives ×16 speed at N = 250
  and makes N ≈ 2300–3300 feasible (≈ 0.2–0.5 s per SCS iteration).

## 4. Sketch of the continuous certificate (I-L9) — notes made while the runs were going

Certificate: PSD kernel K on the placement space P with K(x,x) ≤ λ−1 ∀x and K(x,y) ≤ −1 for all disjoint pairs;
then for any packing x_1..x_n: 0 ≤ Σ_{i,j} K(x_i,x_j) ≤ n(λ−1) − n(n−1) ⇒ n ≤ λ.  (Overlapping pairs are free.)

**The lab's LP certificate IS a kernel certificate in an indicator-feature class.**  Let μ = Σ_p μ_p δ_p be a blocking
measure of total τ (μ(Q) ≥ 1 ∀Q; A07's certificates), m(x) := μ(Q(x)) ≥ 1, and define the feature map
φ(x) = ( 1, ( 1[p ∈ Q(x)] / m(x) )_p ).  Then
   K(x,y) := τ · Σ_p μ_p 1[p∈Q(x)] 1[p∈Q(y)] / (m(x) m(y)) − 1  =  φ(x)ᵀ M φ(y),
   M = (1/τ) Σ_p μ_p (τ e_p − e_0)(τ e_p − e_0)ᵀ ⪰ 0,
satisfies K(x,y) = −1 for disjoint pairs (no common atom) and K(x,x) = τ/m(x) − 1 ≤ τ − 1, i.e. λ = τ.  So the
kernel SDP over M ⪰ 0 on the feature space spanned by (1, coverage indicators of an atom set) is at least as strong
as Theorem 1 on the same atoms, and strictly stronger exactly when it can exploit cross terms M_pq (p ≠ q) that make
K large on OVERLAPPING pairs (the ϑ′ odd-cycle effect) while keeping K ≤ −1 on disjoint pairs.  A low-degree
polynomial/Fourier basis alone will NOT reproduce the LP (the LP measure lives on 1-D curves: Stromquist lines,
corner/edge clusters — A07 §4); the practical basis is "indicators of a few hundred atoms (+ products with a few
smooth D4 features)".  Verification: K is piecewise constant in (x,y) on cells of the atom arrangement in (cx,cy,θ)
(and the constant part is exact rational), so "K(x,y) ≤ −1 for all disjoint pairs" is a finite check over pairs of
cells — the 6-D check reduces to a 3-D cell enumeration (A08-style boxes with the 'undecided atoms ⇒ pattern
enumeration' refinement) plus a pairwise table over cell patterns; the diagonal constraint is a 3-D B&B exactly like
A08's verifier.  Exact PSD of M by rational LDLᵀ.

(Whether this is worth building depends on the discrete numbers of §2: it is only worthwhile if ϑ′ ≪ LP on the same
placement set.)

## 5. Interpretation and verdict

1. **ϑ′ vs LP on the same finite placement graph: 3.84: 10.38 vs 11.000 (gap 0.62); 3.85: 10.43–10.48 vs 11.000
   (gap ≈ 0.55; mid-tilt graph the same; refined grid the same); 3.87: [10.45, 10.64] vs 11.000 (gap ≥ 0.36).**  α = 10 on all these graphs.  So the SDP removes
   roughly half of the LP's integrality gap (11 − 10 = 1) on the discretisation that carries the ¼-structure, and
   on the ¼-structure support alone (§2.0) it is integral.  The ≳ 0.2 criterion of the task is met by a wide margin.
2. **What ϑ′ still cannot do on the grid**: it is not integral (10.45 > 10): B has rank ≈ 120–180 and its diagonal
   keeps the Trump-like shape (corners ≈ 0.93, sides ≈ 0.37 × 8 ≈ 3, interior ≈ 2.5) — a fractional-independent
   structure that gives each side zone ≈ 0.75 instead of 1 and the interior 2.5 instead of 3.
3. **Scaling / discretisation caveat (important)**: the grid LP is 11.000 at 3.84–3.87 only because the ¼-structure
   placements were injected; the continuum LP is 11.02–11.06 there.  ϑ′ on the grid is a LOWER bound on the
   continuum ϑ′ (induced subgraph), so the continuum ϑ′ at 3.85 is ≥ 10.45 and unknown from above; the two grid
   sizes at 3.85 (N = 2229 and N = 3750, same extras) have the same LP (11.000) and the same support-ϑ′ (10.43–10.45 vs 10.40–10.45),
   i.e. no sign of the gap closing with refinement at fixed injected structure (the big-SDP upper bound for N = 3750,
   10.74, is just less converged).  A finite-grid value < 11 proves NOTHING about s(11).
4. **Verdict: ϑ′ − LP gap at 3.84/3.85 ≈ −0.55 to −0.6 on the same placement graph (mid-tilt graph: −0.55);
   continuous kernel version worth building: YES** — with two warnings: (a) the kernel class must contain the LP's
   indicator features (§4), otherwise a smooth low-degree basis will not even reproduce the LP's 10.4–10.7; (b) the
   discrete ϑ′ is still 0.45 above α on the grid, so ϑ′ alone (without case splits) may also cross 11 below 3.877;
   the right next experiment is ϑ′ on a grid WITHOUT injected structures but refined (h = 0.1, Δθ = 2.5°; N ≈ 10⁴ —
   needs a better SDP solver than SCS-on-one-core: 10⁴ nodes = 6·10⁶ pair orbits) or, cheaper and more telling,
   ϑ′ as the NODE relaxation in the A13/A14 case tree (4 corners fixed: LP = 7.000 = budget; is ϑ′ < 7 there?).
5. Cost: the symmetry-reduced SDP at N ≈ 2200 (0.3 M pair orbits, PSD blocks ≈ 280/280/280/280/555) takes ≈ 0.25 s
   per SCS iteration and needs ≳ 3·10⁴ iterations for 1e-3 accuracy (≈ 2 h); N ≈ 500 converges in 15 min.  An
   interior-point solver is out (the E-block alone has 1.5·10⁵ variables); a specialised first-order/augmented-Lagrangian
   SDP solver (or a cutting-plane on the dual with the pair constraints generated lazily — most of the 0.5 M non-edge
   constraints are slack: Z_ij mean −1.2 vs bound −1) is the way to scale.
