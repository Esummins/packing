### What `checkPacking c` checks (all over `Int`, coordinates mean `coord / c.denom`)
1. `0 < denom`, `0 < sideDen`.
2. Every square is a *unit* square: with `e = p1 − p0`, `n = perp e = (−e.y, e.x)`: `e·e = denom²`, and
   (`p2 = p1 + n ∧ p3 = p0 + n`) or (`p2 = p1 − n ∧ p3 = p0 − n`).
3. Every corner strictly inside: `0 < x`, `0 < y`, `x·sideDen < sideNum·denom`, `y·sideDen < sideNum·denom`
   (i.e. `0 < x/D < sideNum/sideDen`).
4. Every unordered pair `(s,t)`: some `n` among the 8 edge vectors of `s` and `t` has
   `∀ a ∈ corners s, ∀ b ∈ corners t, a·n < b·n` or the reverse (strict SAT separation).

## 5. The bridge lemma (NOT formalised) — honest gap

**Claim (bridge).** If `checkPacking c = true` then, with `D = c.denom` and `S = c.sideNum/c.sideDen`,
the 11 closed sets `Q_i = conv{p_{i,0}/D, …, p_{i,3}/D} ⊂ ℝ²` are (a) closed unit squares (side 1),
(b) contained in the closed container `[0,S]²`, and (c) pairwise disjoint. Hence `s(11) ≤ S`.

Proof sketch (elementary):
- (a) from check 2: `|e|=1`, `p2 = p1 + e^⊥`, `p3 = p0 + e^⊥` ⇒ conv of the 4 points is the image of `[0,1]²`
  under the isometry `u ↦ p0/D + u₁ e/D + u₂ e^⊥/D`.
- (b) `[0,S]²` is convex and contains all corners (check 3) ⇒ contains their convex hull.
- (c) SAT soundness: for a vector `n` and points `a = Σλ_i p_i`, `b = Σμ_j q_j` (convex combinations),
  `a·n = Σλ_i (p_i·n) ≤ max_i p_i·n < min_j q_j·n ≤ b·n`, so `a ≠ b`. Any `n` works; only the *inequality
  on corners* is used, so the checker's choice of axes is irrelevant to soundness. Note check 4 with a
  vector `n = 0` cannot succeed (`0 < 0` is false), so degenerate axes are harmless.

What Lean currently proves is only the *Bool computation*; the semantic statement (a)–(c) over ℝ² is
not stated in Lean. Reasons: it needs ℝ, convex hulls / convex combinations, `Finset.sum` and `max` over
finite index sets — i.e. Mathlib (`Real`, `convexHull`, `Finset.sup'`, `inner`) — or at least ℚ with an
ordered-field API. Estimated effort with Mathlib available: **1–2 days** for one pair (define
`Square.toSet : Square → Set (ℝ×ℝ)` as `{p0 + a·e + b·e⊥ | a,b ∈ [0,1]}` — easier than convexHull —,
prove `strictlyBelow n A B = true → Disjoint (toSet s) (toSet t)` by unfolding to a linear-inequality
lemma proven with `nlinarith`/`linarith`, then containment; then lift over `List.all`/`allPairs`
with `List.all_eq_true`, `List.mem_map`, etc.). Half a day more for the full statement over the list.
Using the parametrisation `p0 + a e + b e⊥` instead of `convexHull` avoids all convexity library lemmas:
each of the 4 corners is a value of the affine map, and `a·n` for `a = p0 + αe + βe⊥` is
`(1−α)(1−β)(p0·n) + α(1−β)(p1·n) + αβ(p2·n) + (1−α)β(p3·n)`, a convex combination of corner projections.

## 7. Lower-bound "measure certificate" checker (`PackingCert/Measure.lean`) — style (A) prototype

Semantics (identical in substance to A08's `certs/verify_measure.py`, whose notes I read after writing
v1 and then aligned: `wmin = min(w(t0), w(t1))` for the vacuity/clipping test, `tscale = 2` in the
split rule):
- `MCert = {n, side, atoms : List ⟨px,py,w⟩, fuel}` over `Rat`; `checkMeasure` = all `w ≥ 0`,
  `Σw < n`, and `go fuel [0,1]×[0,side]² atoms 0 = true`.
- Box step: clip centre ranges to `[wLo/2, side − wLo/2]` (empty ⇒ discharged); enclose cos/sin
  by `[cos t1, cos t0]`, `[sin t0, sin t1]`; for each undecided atom compute interval `u, v`;
  inside-for-all atoms add their weight to the inherited `sure` mass, outside-for-all atoms are
  dropped for the subtree, others stay undecided; `sure ≥ 1` ⇒ discharged; else bisect the widest
  dimension (`t` width ×2) if fuel remains, else fail.
- Certificate style: (A) — recursion inside Lean; only data + fuel are supplied. Style (B)
  (explicit box list + witness indices) not implemented: it would trade a few MB of data for a
  trivially linear check and would make kernel `decide` plausible; worth doing if native_decide is
  judged insufficient trust.

Findings:
1. **Degeneracy of "textbook" point sets.** Göbel's set `(1,1),(1,s−1),(s−1,1),(s−1,s−1)` is
   unavoidable for `s ≤ 2+1/√2` but has *zero margin at every s*: the wall-flush upright square
   `[0,1]×[c−½,c+½]` has the atom `x = 1` exactly on its edge. No box method can verify it
   (A08 found the same, "tight" witnesses). Perturbing inward `(1−ε, ·), (s−1+ε, ·)` with ε = 1/50 at
   s = 2.6 gives margin ≈ 0.02 (numerically) and **passes**: `s5_gt_26 : checkMeasure (g26 18) = true`
   (795 boxes; native 43 ms; native_decide ≈ 1 s incl. compilation). Optimised certificates from
   A05/A07 must therefore be "backed off" (they are: A05's set has margin 2e-3).
2. **Real lower-bound certificate checked in Lean:** A05's 10-point set at s = 1870797/500000 =
   3.741594 (`attempts/A08-measure-verify/tests/a05_10pt.json`, weights 1, total 10 < 11):
   `s11_ge_37416 : checkMeasure Data.a05_10pt = true` — 570 943 boxes; **93 s** with the compiled
   executable (`lake exe measure_bench data 40`); **97 s** inside `lake build` via `native_decide`
   (build_measure_log.txt) — so the interpreter overhead is negligible here (Rat ops dominate). A08's Python (integer arithmetic + float prepass): 604 631 boxes, 36 s. Fuel 40 (max depth used ≈ 32).
3. Scaling (compiled exe, `MeasureBench.lean`): per undecided-atom-per-box cost ≈ 5–7 µs (Rat with gcd
   normalisation is the bottleneck); boxes ≈ 800 (margin 0.02) → 3 200 (margin 0.005) for 4 atoms;
   grid stress test 400 atoms/2 547 boxes 2.5 s, 1 521 atoms/23 463 boxes 36 s (before atom sifting:
   14 s and >10 min respectively — sifting = drop provably-outside atoms, inherit sure mass, gives 5–15×).
   Extrapolation for a real 11-square measure certificate (A07 style, ~100–500 atoms after D4
   expansion, margins 1e-3–1e-4): 1e6–1e7 boxes × ~20 undecided atoms ⇒ minutes to a few hours natively;
   the interpreter used by native_decide is ~3–5× slower. Options if too slow: (i) fixed-point `Int`
   arithmetic with outward rounding (also makes kernel `decide` possible — Rat is stuck in the kernel:
   `decide` fails with "Rat.instDecidableLt did not reduce"), (ii) style (B) certificate.
4. Kernel `decide` does **not** work for `checkMeasure` (Rat normalisation via well-founded gcd);
   `native_decide` only. `#print axioms s11_ge_37416` → native_decide axiom.

Bridge lemma for the measure checker (assumed, not formalised): `checkMeasure c = true ⇒ ∀ closed
unit square Q ⊆ [0,side]²: μ(Q) ≥ 1` (needs: θ ∈ [0,π/2] suffices; the box tree covers the whole
admissible parameter set; monotonicity of cos/sin in t on [0,1] and unimodality of cos+sin; interval
arithmetic over-approximates; atoms inside for all params of a box stay inside for sub-boxes) and then
`⇒ no n disjoint closed unit squares in [0,side]² ⇒ s(n) ≥ side`. Mathlib effort estimate: 3–5 days
(real trigonometry of the half-angle substitution is the annoying part; the B&B soundness is a clean
induction on `go`).
