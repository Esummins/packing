### What `checkPacking c` checks (all over `Int`, coordinates mean `coord / c.denom`)
1. `0 < denom`, `0 < sideDen`.
2. Every square is a *unit* square: with `e = p1 − p0`, `n = perp e = (−e.y, e.x)`: `e·e = denom²`, and
   (`p2 = p1 + n ∧ p3 = p0 + n`) or (`p2 = p1 − n ∧ p3 = p0 − n`).
3. Every corner strictly inside: `0 < x`, `0 < y`, `x·sideDen < sideNum·denom`, `y·sideDen < sideNum·denom`
   (i.e. `0 < x/D < sideNum/sideDen`).
4. Every unordered pair `(s,t)`: some `n` among the 8 edge vectors of `s` and `t` has
   `∀ a ∈ corners s, ∀ b ∈ corners t, a·n < b·n` or the reverse (strict SAT separation).

## 5. The bridge lemma (NOT formalised) — honest gap

**Claim (bridge).** If `checkPacking c = true` then, with `D = c.denom` and `S = c.sideNum/c.sideDen`,
the 11 closed sets `Q_i = conv{p_{i,0}/D, …, p_{i,3}/D} ⊂ ℝ²` are (a) closed unit squares (side 1),
(b) contained in the closed container `[0,S]²`, and (c) pairwise disjoint. Hence `s(11) ≤ S`.

Proof sketch (elementary):
- (a) from check 2: `|e|=1`, `p2 = p1 + e^⊥`, `p3 = p0 + e^⊥` ⇒ conv of the 4 points is the image of `[0,1]²`
  under the isometry `u ↦ p0/D + u₁ e/D + u₂ e^⊥/D`.
- (b) `[0,S]²` is convex and contains all corners (check 3) ⇒ contains their convex hull.
- (c) SAT soundness: for a vector `n` and points `a = Σλ_i p_i`, `b = Σμ_j q_j` (convex combinations),
  `a·n = Σλ_i (p_i·n) ≤ max_i p_i·n < min_j q_j·n ≤ b·n`, so `a ≠ b`. Any `n` works; only the *inequality
  on corners* is used, so the checker's choice of axes is irrelevant to soundness. Note check 4 with a
  vector `n = 0` cannot succeed (`0 < 0` is false), so degenerate axes are harmless.

What Lean currently proves is only the *Bool computation*; the semantic statement (a)–(c) over ℝ² is
not stated in Lean. Reasons: it needs ℝ, convex hulls / convex combinations, `Finset.sum` and `max` over
finite index sets — i.e. Mathlib (`Real`, `convexHull`, `Finset.sup'`, `inner`) — or at least ℚ with an
ordered-field API. Estimated effort with Mathlib available: **1–2 days** for one pair (define
`Square.toSet : Square → Set (ℝ×ℝ)` as `{p0 + a·e + b·e⊥ | a,b ∈ [0,1]}` — easier than convexHull —,
prove `strictlyBelow n A B = true → Disjoint (toSet s) (toSet t)` by unfolding to a linear-inequality
lemma proven with `nlinarith`/`linarith`, then containment; then lift over `List.all`/`allPairs`
with `List.all_eq_true`, `List.mem_map`, etc.). Half a day more for the full statement over the list.
Using the parametrisation `p0 + a e + b e⊥` instead of `convexHull` avoids all convexity library lemmas:
each of the 4 corners is a value of the affine map, and `a·n` for `a = p0 + αe + βe⊥` is
`(1−α)(1−β)(p0·n) + α(1−β)(p1·n) + αβ(p2·n) + (1−α)β(p3·n)`, a convex combination of corner projections.
