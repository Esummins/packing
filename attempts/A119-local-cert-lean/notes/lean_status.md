**One project axiom**, `PackingCert.S11.LocalCert.sat_selection`, with exact statement:

```lean
axiom sat_selection (qw qo : PSq)
    (h : Disjoint (interior qw.set) (interior qo.set)) :
    (∃ k : Bool, ∃ eps : ℝ, (eps = 1 ∨ eps = -1) ∧ 0 ≤ gsel qw qo k eps) ∨
    (∃ k : Bool, ∃ eps : ℝ, (eps = 1 ∨ eps = -1) ∧ 0 ≤ gsel qo qw k eps)
```

with

```lean
def axk (q : PSq) (k : Bool) : ℝ × ℝ :=
  if k then (-(sinT q.t), cosT q.t) else (cosT q.t, sinT q.t)

def wrel (qw qo : PSq) : ℝ :=
  |cosT qw.t * cosT qo.t + sinT qw.t * sinT qo.t| +
    |cosT qw.t * sinT qo.t - sinT qw.t * cosT qo.t|

def gsel (qw qo : PSq) (k : Bool) (eps : ℝ) : ℝ :=
  eps * ((qo.cx - qw.cx) * (axk qw k).1 + (qo.cy - qw.cy) * (axk qw k).2)
    - 1 / 2 - wrel qw qo / 2
```

This is **Lemma SAT for INTERIORS** (`docs/proofs/local_certificate.md` §1), the ⇒ direction
Lemma COVER uses.  `CaseSat.sat_squares` already proves the closed-square form — if the four
projection-overlap inequalities hold (`|d₁| ≤ a + (c+|s|)/2`, `|d₂| ≤ …`, and the two rotated ones,
with `a = 1/2`), the squares MEET.  The remaining step is the shrink argument of §1: with all
eight gaps strictly negative the four overlaps are proper, so both squares may be scaled about
their centres by some `λ < 1` and the scaled picture still satisfies `sat_squares`; a common point
of the scaled squares is an INTERIOR point of both originals.  Formalising the choice of `λ` (a
max over four ratios) is the open work; it is bounded, standard, and independent of everything
else in the file.

## What is NOT in Lean

`LocalDead Ls Ps shat` is **not derived inside Lean for any concrete `N`**.  That derivation is
the recorded finite cover — the bisection tree over the tilt box, the selection case split per
near pair, the impossible selections by interval enclosure, and one `leaf_*` kill per closed leaf
— and it is performed, and independently re-verified in exact rational arithmetic, by
`attempts/A119-local-cert-lean/code/check_local.py` on the certificate files of
`attempts/A119-local-cert-lean/certs/`.  Importing that cover into Lean means either (a) emitting
one `leaf_*` theorem per closed leaf and one `rcases` chain per cell — feasible in size for the
small `N` (8 leaves) and not for the large ones (10³–10⁴ leaves) — or (b) the A78/A93 route: a
Lean-side certificate CHECKER over the file with `native_decide`, i.e. a verified rational LP /
interval kernel.  (b) is the recommended next step and is the same shape as `checkCaseI` /
`checkAtlas`.
