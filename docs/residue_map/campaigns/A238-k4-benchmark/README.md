# A238 — the k5 toolkit on the Trump-parent protected classes (k4_11, k3_02)

Pages written by `attempts/A238-k4-benchmark/code/pages238.py` from the certificates
`attempts/A238-k4-benchmark/certs/k4bench238_<nid>.json`.

A page here is ONE node of a protected class's tree at s0: the class pins as slack pin cores
(delta_pin = 2e-2), one conditioned free square H (a cell of A100/A84's level-1 cover of the interior
zone, or the whole zone for `<cls>_root`), the rest anonymous.  The hypothesis each page certifies is
M_S & YES(H) and a DEAD verdict is the instance of `stratum_kill` for that class restricted to H
(Lemma K1 / Lemma P-TREE (c); `docs/proofs/protected_trees.md`).  Purple = the node contains a D4
image of Trump (GATED: no kill rule may be applied there); dark green = a TRUMP-TUBE (D) leaf.
